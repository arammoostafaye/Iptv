### 📱 How to Use

#### TiviMate (Recommended)
1. Open TiviMate → Settings → Playlists → Add Playlist
2. Paste: `https://raw.githubusercontent.com/arammoostafaye/Iptv/main/list.m3u`
3. EPG: `https://iptv-org.github.io/epg/guides.xml` (optional)
4. Done — auto updates every 6h

#### VLC
Media → Open Network Stream → Paste M3U URL → Play

#### Kodi
Add-ons → PVR Clients → PVR IPTV Simple Client → Configure → M3U URL

### 🛠️ Self-Host

```bash
git clone https://github.com/arammoostafaye/Iptv
cd Iptv
pip install -r requirements.txt

# Fast test (100 channels)
IPTV_LIMIT=100 python update_iptv_v2.py

# Full build
python update_iptv_v2.py

# With custom premium
echo "http://server:8080/get.php?username=...&password=...&type=m3u_plus" > premium_sources.txt
python update_iptv_v2.py
```

Enable Pages: `Settings → Pages → Source: gh-pages`
